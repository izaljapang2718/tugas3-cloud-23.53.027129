Materi Komputasi Awan

Mengenal teknologi Cloud Computing

1. Pengertian Komputasi Awan

Komputasi awan atau Cloud Computing adalah teknologi yang memungkinkan pengguna menggunakan sumber daya komputasi melalui jaringan internet. Sumber daya tersebut dapat berupa penyimpanan data, server, jaringan, dan perangkat lunak.

Dengan adanya komputasi awan, pengguna tidak harus memiliki seluruh perangkat keras sendiri karena layanan dapat digunakan melalui penyedia cloud.

2. Software as a Service (SaaS)

SaaS merupakan layanan cloud yang menyediakan perangkat lunak siap digunakan melalui internet. Pengguna tidak perlu melakukan instalasi atau mengelola server sendiri.

Contoh: Google Drive, Gmail, dan Google Docs.

3. Platform as a Service (PaaS)

PaaS merupakan layanan cloud yang menyediakan platform untuk mengembangkan, menguji, dan menjalankan aplikasi. Pengembang dapat lebih fokus pada pembuatan aplikasi tanpa mengelola seluruh infrastruktur server.

4. Infrastructure as a Service (IaaS)

IaaS merupakan layanan cloud yang menyediakan infrastruktur teknologi seperti server virtual, penyimpanan, dan jaringan melalui internet. Pengguna dapat mengatur sistem operasi dan aplikasi sesuai kebutuhan.

5. Manfaat Komputasi Awan

  • Menghemat biaya pembelian perangkat keras.
  • Data dapat diakses melalui internet.
  • Memudahkan kerja sama dan berbagi informasi.
  • Kapasitas penyimpanan dapat disesuaikan.
  • Memudahkan pengelolaan aplikasi dan data.

6. Risiko Penggunaan Cloud

  • Risiko kebocoran data pribadi.
  • Ketergantungan terhadap koneksi internet.
  • Gangguan layanan dari penyedia cloud.
  • Risiko akses tidak sah ke akun.
  • Biaya layanan dapat meningkat.
